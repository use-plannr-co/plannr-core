## Key RN design tokens applied everywhere
- Background: `Color.plBackground` (#FFFFFF / #222222)
- Card bg: `Color.plComp` (#FFFFFF / #171717)
- Input bg: `Color.plInput` (#F0F0F0 / #2E2E2E)
- Shadow: `plShadow(radius:)` → opacity 0.1, x:0, y:0
- Border radius: 12 standard, 20 edit cards, 32 nav pill
- Titles: `.system(.rounded, weight: .black)` (PinkSunset equiv)
- Gradient: `LinearGradient.plPurple` (#856BD3 → #B79FFF)
- Nav bar: `Color.plNavbar` (#000 / #171717), Capsule shape
